Workspace windows

Switch without closing tabs. Native pins belong to each workspace window. Automatic shelving is paused in this live-window prototype.

Pin one workspace to keep it alongside the one you’re using. Pinning another replaces it and switches to that window; clicking its pin again clears it. Use the pin icons in the popup or the checkboxes below. Pins do not make windows always-on-top.

Shortcuts: Option/Alt+Shift+Space searches; Option/Alt+Shift+P returns to the previous workspace. Option/Alt+1 and +2 select their assigned slots. Configure key bindings for 3–9 and 0 below; slot 0 always opens Read Later. Chromium supports neither backtick commands nor more than four default assignments.

Ordinary switching never closes tabs. A closed workspace can reopen its last saved URLs and pins, but not unsaved forms or full page state. After a browser restart, unmatched windows can be attached explicitly from the popup.

Workspace shortcuts

Slots 1–9 stay fixed. Drag active workspaces into slots or use the dropdowns. Drag between occupied slots to swap. Changes save immediately.

Unassigned active workspaces. Drag a slotted workspace here to clear its slot. Putting away a workspace leaves a gap; resuming does not reclaim it.

Contexts

Names, colours, and order map directly to Helium’s native groups.

Strict routes

Add sites that belong to one context every time. Each hostname includes all its subdomains. More-specific hostnames override broader ones. Routed sites stay out of automatic Read Later.

Change a saved route’s destination below. Changes save immediately; existing tabs stay where they are.

Workspaces

Save selected tabs from the popup for a client or task. Workspaces live inside buckets, not as permanent extra groups. Opening adds missing pages; it never closes tabs.

Lifecycle

The hourly sweep moves stale work to Inactive—not Read Later—and unloads idle shelved tabs without closing anything.

Backup

Keep a portable copy before reinstalling Rauiri or moving to another browser profile.

Full backups include saved page URLs, which may contain private client information or access tokens. Keep them private. Configuration-only exports omit saved pages and workspace URL sets. Imports replace saved state; a pre-import backup is retained locally. Open tabs are never closed.
